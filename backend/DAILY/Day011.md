## 关键回顾
1. String 不可变；多次字符串拼接优先使用 StringBuilder。
2. StringBuffer 方法带同步，线程安全但通常比 StringBuilder 慢。
3. 包装类用于泛型和工具方法；比较对象值使用 `equals()`，避免依赖 Integer 缓存。
4. 日期时间优先使用 `java.time`，避免旧版 Date 的可变性问题。
5. 验证回文串的双指针解法可在 O(n) 时间、O(1) 额外空间内完成。
