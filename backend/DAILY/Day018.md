## 关键收获
- MyBatis 核心流程：config.xml → SqlSessionFactory → SqlSession → Mapper
- POOLED DataSource 自带连接池，无需额外配置
- `useGeneratedKeys="true"` + `keyProperty="id"` 自动获取自增ID
- XML mapper 的参数占位符 `#{}` 防注入（底层是 PreparedStatement）
- 多参数传参需用 Map 或 JavaBean 包装，不能直接传数组
