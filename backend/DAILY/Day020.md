## 关键技术
- **association**: ResultMap 中映射单个关联对象，通过 JOIN 别名区分同名字段
- **一对多**: Java 层循环查子表组装 List（避免 N+1 可改用 `collection` 子查询/嵌套结果）
- **choose/when/otherwise**: 动态 SQL 中的 if-elseif-else 语义，比 `<if>` 更严谨
- **LeetCode 234**: O(n) 时间 + O(1) 空间，核心是快慢指针找中点 + 原地反转
