## 三层架构现状

```
Controller (@RestController)
  → Service (@Service, 业务逻辑 + 校验)
    → Mapper (@Mapper, 数据访问)

DeviceController  → DeviceService  → DeviceMapper  (注解)
ProductController → ProductMapper  (XML ResultMap)
```

## 踩坑
- `mapper-locations` 需显式添加 `classpath:mapper/**/*Mapper.xml`（Spring Boot 不会自动扫）
- ProductMapper 既要有 @Mapper 注解也要有 XML（namespace 对应）
