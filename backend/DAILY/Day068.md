## 一、交付范围

### 1. Spring AI @Tool 声明式工具注册（ADR 0023，零手写 JSON Schema）

| 项 | 交付 |
|----|------|
| 工具集 | `dev.reboot.tool.DeviceAiTools`（@Component）：`get_device_basic`（设备基础信息）/ `list_device_recent_alarms`（单设备最近告警，默认 5 条）/ `list_active_alarms_by_site`（站点未处理告警，默认 10 条），全部经 `@Tool`/`@ToolParam` 声明，`ToolCallbacks.from(bean)` 生成 `ToolCallback[]` |
| 站点作用域 | 当前用户 ID 经 `ToolContext` 传入工具，工具内 `SiteAccessService.assertSiteAccess(VIEWER)`（ADR 0020）；403/404 返回 `{"error": "..."}` JSON 让模型如实解释，不整轮失败 |
| 新 Mapper | `AlarmMapper.findActiveBySiteId(siteId, limit)`（JOIN device 过滤未删除 + 站点）→ `AlarmSiteVO` |

### 2. Agent 循环 + 新接口

| 项 | 交付 |
|----|------|
| Agent | `DeviceStatusAgentService`：系统提示词 + 设备上下文预置 → 手动工具循环（每轮 `internalToolExecutionEnabled=false`，因 Spring AI 自动循环无上限）；工具结果以 `ToolResponseMessage` 回填对话 |
| 回退 | 最大 **3 轮**工具调用硬限（`MAX_TOOL_ROUNDS=3`）：达到后追加收尾提示并无工具调用一次，`truncated=true`；模型未调用工具直接回答 → `referencedRealTime=false` |
| 新接口 | `POST /api/ai/agents/device-status`（`AiDeviceStatusRequest{deviceId, question}` → `AiDeviceStatusResult{answer, toolRounds, toolCalls, referencedRealTime, truncated, toolTrace}`），`@RequireRole(VIEWER+)` |
| 前端 | `DeviceDetail.vue` 新增「AI 设备问答」折叠面板（`el-collapse`）：输入问题 → 展示回答 + 「已参考/未参考实时数据」徽标 + 工具调用次数/轮次 + 工具轨迹 chips + 3 轮上限警示；`aiApi.deviceStatus(deviceId, question)` |

### 3. 审计（Flyway V10 + @OperationLog）

| 项 | 交付 |
|----|------|
| Flyway V10 | `V10__function_call_operation_type.sql`：`chk_operation_type` 扩展 `FUNCTION_CALL`（`target_type=AI` 已由 V9 覆盖）；H2 test schema 同步 |
| 注解能力 | `OperationLogAspect` 捕获返回值并支持 `{ret}` 占位符（null → "null"，超 400 字截断）；`@OperationLog` javadoc 同步 |
| 端点埋点 | 新端点 `@OperationLog(operationType="FUNCTION_CALL", targetType="AI", description="AI 设备状态问答（工具调用） {ret}")` → 审计记录设备 ID / 轮次 / 调用数 / 是否参考实时数据（`AiDeviceStatusResult.toString()`） |
