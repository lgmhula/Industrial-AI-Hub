1. ./mvnw test                          → 360 tests / 0 failures / 0 errors（+1 指标测试）

   mqtt_ingest_messages_total{device_code="esp32-dht-001",outcome="ok"} 13.0   ← ESP32 重连即实时计数

## 三、踩坑

1. **application.yml 重复顶级键**：已有 `management:` 段（Day 37 只暴露 health），
   直接新增第二个 → SnakeYAML `DuplicateKeyException` → **4 个 @SpringBootTest 上下文
   全挂（7 errors）**。修复=合并进既有段。教训：**往 application.yml 加顶级键前先 grep**；
2. 后台跑 `./mvnw test | tail` 会吞输出且管道码掩盖失败——全量回归必须保留完整输出再过滤。
