## 三、本日确认的关键口径

| 主题 | 项目事实 | 面试边界 |
|------|----------|----------|
| 集合 | `SseEmitterRegistry`、限流桶、`SimpleVectorStore` 使用 `ConcurrentHashMap` | 只保证单 JVM 容器结构安全，不代表分布式状态 |
| SSE 注册 | 同一 userId 常规路径覆盖旧 emitter，回调与 `@PreDestroy` 清理 | 先 get 再 put 不是原子组合；并发重复建连仍有覆盖竞态 |
| 限流 | Guava 路径桶 + `AtomicLong` CAS 日志节流 | per-JVM 限流，不是 Redis 全局限流 |
| RabbitMQ 去重 | `AlarmConsumer` 使用进程内 deliveryTag Map | 无清理、无跨实例保证，不能声称可靠幂等 |
| MQTT 幂等 | 字段级 Redis SETNX，TTL 24h；Redis 异常时继续落库 | 跨实例受 Redis 覆盖，但故障时接受重复，非绝对 exactly-once |
| 线程池 | 登录审计 2/4/1000 + `@Async`，异常不影响登录主流程 | 未做容量压测；审计可能丢失，不是可靠消息 |
| JVM | Java 25、容器默认内存/GC、无 `-Xmx`/GC 选型；Day 103 观测 GC pause max 27ms | 有观测但未调优，27ms 不是生产 SLO |
| Spring | 构造器注入、事务、Cache、AOP、Filter/Interceptor、条件装配均有代码证据 | `@Transactional` 不覆盖 Redis/MQ/RabbitMQ，缓存不保证强一致 |
| RAG | `SimpleVectorStore + LocalHashEmbeddingModel` | 不是 Qdrant，不是生产级向量检索 |
