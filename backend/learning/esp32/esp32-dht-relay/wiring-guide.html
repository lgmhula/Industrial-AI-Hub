0. 先搞懂：这套东西最后要干什么

你买的零件拼好、烧录固件后，会组成一个真实传感器 → 平台的闭环（这就是"项目所需要的场景环境"）：

DHT22 测温湿度 → ESP32 每2秒发到 EMQX(1883) → 后端落库 device_data → 湿度>90% 触发报警 →
后端下发 RELAY_ON → 继电器吸合3秒 → （你哈气就能演示）

⚠️ 重要：你买的设备里，这次只接 3 件。 OLED 屏、BH1750 光照传感器、第2块 ESP32 是以后阶段才用，当前固件没写它们，现在不接，接了反而乱。等这套跑通了再扩展。

2. 五步拼装（像乐高，一步加一根/一组线）

步骤 1 · 把 ESP32 放上面包板

1
把 ESP32-S3 跨在面包板中间的凹槽上（板子两排针脚分别插在凹槽两侧，别插同一排，否则会短路）。 Type-C 口朝左，方便插 USB 线。

步骤 2 · 铺两条"电源轨"（先给面包板通电）

2
用杜邦线把 ESP32 的电源引到面包板两侧的供电条上，后面 DHT22 和继电器都从这两条"轨道"取电：
  • 橙线：ESP32 3V3 → 面包板上排红条（给 DHT22 用）
  • 红线：ESP32 5V → 面包板下排红条（给继电器用）
  • 黑线×2：ESP32 GND → 上下两条蓝条（并用一根黑线把上下蓝条连起来，保证共地）

步骤 3 · 接 DHT22（温湿度）

3
DHT22 模块有 3 个脚：VCC / DATA / GND（从左到右）。按颜色接：
  • 橙线：DHT22 VCC → 面包板上排红条(3V3)
  • 黑线：DHT22 GND → 面包板上排蓝条(GND)
  • 黄线：DHT22 DATA → ESP32 GPIO4
裸件提醒：如果你的 DHT22 是 4 脚裸件（没有小板），DATA 和 VCC 之间要串一个 10kΩ 电阻当上拉； 如果是带小绿/蓝板的模块版，板子已自带，直接接就行。

步骤 4 · 接继电器（执行器）

4
继电器模块控制侧有 3 个脚：VCC / GND / IN。按颜色接：
  • 红线：继电器 VCC → 面包板下排红条(5V)
  • 黑线：继电器 GND → 面包板下排蓝条(GND)
  • 绿线：继电器 IN → ESP32 GPIO14
触发方向：固件设的是低电平触发（IN 收到低电平→吸合）。模块上若有个 JD-VCC 跳线帽， 保持默认插着即可（VCC 和 JD-VCC 连通）。烧录后看模块上的 LED：IN 变低时灯亮=吸合。

步骤 5 · 全部接好 = 最终总装图

5
把步骤 2~4 的线全插上，就是下面这张完整总装图。照着颜色一根根核对，确认没接错再通电。

4. ⚠️ 安全与排错（先看这个再通电）

强电警告：继电器输出侧 COM/NO/NC 是高压隔离区。新手阶段千万不要接 220V 交流电！ 验证继电器有没有跳，用你已有的万用表 9205 蜂鸣档测 COM 和 NO 之间的通断就行—— 吸合时蜂鸣响（导通），复位时无声（断开）。这样既安全又能确认整条链路通了。
常见坑：
  • ESP32 只能接 3V3 信号，别把 5V 接到 GPIO 脚上，会烧板子。
  • DHT22 读出来是 NaN → 九成是橙/黑线反了或 DATA 没上拉（裸件加 10k）。
  • 继电器不动作 → IN 触发电平反了，改 esp32-dht-relay.ino 里的 RELAY_ON_LEVEL。
  • 避开 GPIO0 / 3 / 45 / 46（strapping 脚），本图用的是 4 和 5，安全。

5. 接好之后，怎么跟你的项目联动

  1. 电脑上确保 EMQX 在跑：docker compose up -d emqx（Dashboard http://localhost:18083）。
  2. 打开 esp32-dht-relay.ino，改顶部 3 处：WIFI_SSID / WIFI_PASSWORD / MQTT_HOST（填你 Mac 的局域网 IP，ipconfig getifaddr en0 查）。
  3. Arduino IDE：装 esp32 板包 + PubSubClient + Adafruit DHT 库；板型选 ESP32S3 Dev Module；原生 USB 板把 USB CDC On Boot: Enabled。
  4. 烧录 → 打开串口监视器(115200)：看到 [wifi] 已连接 和 [mqtt] 已订阅 .../command 就成功了。
  5. 我对 DHT22 哈气几秒（湿度>90%）→ 后端报警落库 → 下发 RELAY_ON → 继电器吸合 3 秒（串口打 [relay] ON）。闭环完成！
