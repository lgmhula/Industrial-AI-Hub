# ADR-0007: JDK 25 LTS 作为唯一运行时

**日期:** 2026-07-11  
**状态:** Accepted  
**决策者:** hula0710

## 背景

项目恢复初期面临 JDK 版本选择：系统原有 JDK 8/17/21 残留，需要确定唯一运行时。

## 决策

采用 JDK 25 LTS (Temurin) 作为唯一运行时。

## 理由

1. Oracle 2025 年将 LTS 节奏调整为 2 年：17 → 21 → 25
2. JDK 25 是当前最新 LTS，支持周期最长（至 2033 年）
3. Virtual Threads (Project Loom) 在 21 已正式 GA，25 更成熟
4. Spring Boot 3.5 已官方支持 JDK 25
5. 项目无历史包袱，可直接采用最前向版本

## 后果

- Maven 3.9.6 部分内部 API 有迁移警告（无害）
- 需要 `.mvn/jvm.config` 配置 `--enable-native-access=ALL-UNNAMED`
- 部分第三方库可能尚未完全适配（以编译/运行时验证为准）
