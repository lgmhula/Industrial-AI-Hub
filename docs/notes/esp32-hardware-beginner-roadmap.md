# ESP32 硬件零基础学习路线（Day 99 入门支线）

> 适用：hula0710（硬件散件、零接线经验、刚装 Arduino IDE）。
> 目标：从「零件都不认识」到「ESP32+DHT22+继电器 → EMQX → 后端闭环」（Day 99 P2/P3）。
> 原则：**关卡制 + 每关有成功信号**，不跳关、不慌；所有硬件操作必须**断电接线**。

## 1. 你的零件都是什么（一句话认识）

| 零件 | 是什么 | 在本项目的角色 |
|------|--------|---------------|
| **ESP32-S3-N16R8 ×2** | 一台带 WiFi/BLE 的「小电脑」 | 主控：烧程序、读传感器、发 MQTT（用 #1） |
| **DHT22 ×2** | 数字温湿度传感器 | 上报 temperature/humidity，哈气触发演示 |
| **GY-302 BH1750 ×1** | 光照度传感器（I2C） | 后续可选第二闭环 |
| **0.96" OLED ×2** | I2C 小屏幕 | 后续本地显示 |
| **1 路继电器 ×1** | 低压信号控制的「电子开关」 | 执行器：收到 RELAY_ON 跳变 |
| **9205 万用表** | 测电压/通断 | 排错 + 验证继电器 COM-NO 通断 |
| **Arduino 学习套件** | 面包板 + 杜邦线 + LED/电阻/按键等 | 练习平台 + 本项目接线的工具来源 |

## 2. 三个必须懂的核心概念（3 分钟版）

1. **电路必须「闭合成回路」**：任何模块要工作，至少接 2 根线——电源（VCC/+/3V3/5V）和
   地（GND/−），再加 1 根**信号线**让主控读写数据。
2. **面包板**：上下两条长轨是电源（红色 +，蓝色 −，通常左右各一组）；中间每列 5 个孔
   **内部连通**（插同一列 = 接在一起）。电源轨之间用杜邦线接到 ESP32 的 3V3/GND。
3. **安全三不**：不反接电源（+/− 接反可能烧件）；不把 5V 灌进 ESP32 的 3.3V 引脚；
   **接线时拔掉 USB 断电**，插好再上电。

## 3. 关卡路线（每关都小步可验证）

| 关卡 | 做什么 | 学什么 | 成功信号 |
|:--:|--------|--------|---------|
| 0 | **Blink**：让 ESP32 板载 LED 闪烁 | IDE 上传流程、开发板/端口选择 | 板上小灯 1s 亮/灭循环 |
| 1 | **串口 Hello**：Serial Monitor 打印 | 原生 USB 的 CDC 设置、串口监视器 | 每 1s 打印一行 Hello |
| 2 | **面包板 LED**：GPIO 点亮外接 LED | 面包板/杜邦线/GPIO 输出/限流电阻 | 外接 LED 亮灭可编程 |
| 3 | **DHT22 读数** | 传感器接线 + DHT 库 + 读数/NaN 排查 | 串口打印温湿度 |
| 4 | **WiFi 联网** | WiFi.begin、打印 IP | 打印出局域网 IP |
| 5 | **MQTT 上报**（复用 Day99 固件 telemetry 段） | PubSubClient、连 EMQX | 后端 device_data 出现该设备数据（我帮你查库确认） |
| 6 | **command 下行 + 继电器**（Day99 P3 闭环） | 订阅 command、继电器吸合 3s | 后端 RELAY_ON → 继电器跳变 |

> 关卡 0-2 建议在 **Arduino 学习套件 + ESP32** 上完成（用套件里的面包板/杜邦线/LED/电阻即可，
> 不需要额外东西）。关卡 5-6 回到本项目 Day99 链路。

## 5. 每关需要的“前置动作”速查

- **装 ESP32 支持包**：Arduino IDE → `文件→首选项→附加开发板管理器网址` 填
  `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
  → `工具→开发板→开发板管理器` 搜 **esp32** → 装 **esp32 by Espressif Systems**（3.x，首次下载较慢）。
- **选板**：`工具→开发板→ESP32 Arduino→ESP32S3 Dev Module`。
- **原生 USB 板（无串口芯片）**：`工具→USB CDC On Boot: Enabled`，否则上传/串口不可用。
- **插 USB 后**：`工具→端口` 选新出现的串口；打开 `工具→串口监视器`，波特率 115200。

## 6. 排错速查（先自查再问我）

| 现象 | 可能原因 / 动作 |
|------|----------------|
| 上传报 `Failed to connect` / 卡在 Connecting | USB 线是否数据线（非只充电）；换口；USB CDC On Boot；板子按住 Boot 键再点上传（上电瞬间进入下载模式） |
| `开发板 esp32 未安装` | 检查步骤「装 ESP32 支持包」；国内网络慢→搜「esp32 离线安装包」 |
| 端口列表为空 | 换 USB 线/口；重启 IDE；macOS 免驱多正常，插上后 ls /dev/cu.* 应出现 |
| 串口乱码 | 波特率必须 115200 |
| DHT 读 NaN | 接线（VCC/GND/信号对上）、数据脚与 3V3 间 10kΩ 上拉（模块版多数自带）、两次读取间隔 ≥2s |
