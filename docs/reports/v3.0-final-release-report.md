## 一、发布结论

Industrial AI Hub 完成官方 112 天路线图并通过最终发布预演，可以 `v3.0-final` 作为求职展示、复现和后续演进的稳定检查点。

本版本包含：

- 可运行的模块化单体后端与 Vue 3 前端；
- 真实 ESP32-S3 + DHT22 + 继电器双向物理闭环；
- MQTT、Redis、RabbitMQ、MySQL、EMQX 生产型接入模式；
- AI 告警摘要、设备诊断、RAG、Agent 巡检和 AI 自动报警；
- Prometheus、traceId、滚动日志、JMeter 压测证据；
- Docker Compose v1.7 宿主机/容器双路径和 full profile 15 服务预演；
- 37 份 ADR、每日日志、周复盘、踩坑手册、面试材料与发布文档。

`v3.0-final` 不是生产级高可用承诺。当前系统仍是单机模块化单体，多副本、浏览器级 SSE E2E、报警合并和 Qdrant 等能力属于后续演进。

## 二、发布范围

### 2.1 功能范围

| 领域 | 已交付能力 |
|------|------------|
| 认证权限 | JWT、BCrypt、三级 RBAC、站点作用域、Token 黑名单、登录审计 |
| 设备业务 | 设备 CRUD、遥测查询、统计、报警工作流、操作日志 |
| IoT | MQTT QoS1 上行、Redis 幂等、LWT、继电器 command 下行 |
| 消息 | RabbitMQ 工作队列、Fanout、DLQ、延迟检查和手动 ACK |
| AI | DeepSeek opt-in、摘要、诊断、RAG、Agent、MCP、自动报警 |
| 推送 | RabbitMQ + Redis + SSE Gateway + 浏览器订阅 |
| 观测 | Actuator、Prometheus、三条 MQTT 业务指标、traceId、滚动日志 |
| 交付 | Compose core/full、Dockerfile、Nginx、部署 Runbook、种子脚本 |

### 2.2 不在本次发布承诺内

- 生产级高可用、SLA/SLO 或线上容量承诺；
- Kubernetes、服务网格或业务微服务拆分；
- 浏览器级 SSE E2E 全覆盖；
- Qdrant 或生产级向量数据库；
- 跨实例 SSE 会话、Redis 分布式限流和集中日志；
- 报警风暴合并去重；
- 前端容器化和 Grafana 仪表盘；
- 多台真实设备的规模验证。

## 五、已知风险与边界

| 风险/边界 | 当前事实 | 后续建议 |
|-----------|----------|----------|
| SSE 浏览器 E2E | RabbitMQ/Redis 链路有 IT，浏览器 E2E 未补 | 使用 Playwright 覆盖连接、推送、重连、清理 |

## 七、Tag 与复现

发布 tag 必须指向实际合并后的 `main` commit：

```bash
git switch main
git pull --ff-only
git rev-parse main
git rev-parse 'v3.0-final^{commit}'
```

两个 commit hash 必须一致。复现入口：

```bash
cp .env.example .env
docker compose up -d
curl http://localhost:8080/actuator/health

cd backend && ./mvnw test
cd ../frontend && npm run build
```

详细部署见 `docs/SETUP.md` 与 `docs/reports/deploy-runbook-new-device.md`。
